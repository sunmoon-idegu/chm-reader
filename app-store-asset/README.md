# App Store Connect 填寫對照（1.1.0）

| App Store Connect 欄位 | 檔案 | 限制 |
|---|---|---|
| 名稱、副標題 | `0-名稱與副標題.txt` | 各 30 字 |
| 行銷宣傳文字 | `1-行銷宣傳文字.txt` | 170 字 |
| 描述 | `2-描述.txt` | 4000 字 |
| 關鍵字 | `3-關鍵字.txt` | 100 字元，逗號分隔；不要重複名稱裡已有的字 |
| 版權 | `4-版權.txt` | |
| 此版本的新增內容 | `5-此版本新增內容.txt` | 更新版本必填 |
| App 審查資訊 → 備註 | `6-審查備註.txt` | |
| App 預覽和截圖（Mac） | `screenshots/`，依編號順序上傳 | 2560×1600，16:10 |
| App 圖示 | `app-icon-1024.png` | 已內建在 App 中，上傳建置版本後自動帶入 |
| 支援網址 | https://sunmoon-idegu.github.io/chm-reader/ | |
| 隱私權政策網址 | https://sunmoon-idegu.github.io/chm-reader/privacy.html | |

其他欄位：類別「書籍」（次要「參考」）、App 隱私權選「不收集資料」。

## 截圖
1. 閱讀與筆記：CHM（米黃背景），螢光標記與右側筆記欄
2. 全文搜尋：搜尋「阿賴耶識」，結果依頁面列出，點選後在內文選取
3. 並排閱讀：左側 CHM 講記，右側《論語》PDF
4. PDF 閱讀：書籤目錄、螢光標記與筆記
5. 夜間模式

CHM 畫面使用《瑜伽師地論筆錄》；PDF 使用 `demo/論語選讀.pdf`（公有領域文本，由 `scripts/make-demo-pdf.swift` 產生）。
