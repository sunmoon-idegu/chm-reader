CHM 閱讀器

繁體中文 CHM 電子書閱讀與筆記 · macOS

在 Mac 上舒適地閱讀 CHM 電子書，特別適合繁體中文的經典、講記與參考書。 正確顯示 Big5 舊檔，選字即可螢光標記、在側欄寫筆記，並自由調整字型、字級、行距與背景色。

常見問題

怎麼標記和寫筆記？
選取文字後按工具列的螢光筆（或 ⌥⌘H）。點螢光文字，右側筆記欄就會展開，輸入內容會自動儲存。

顯示亂碼怎麼辦？
本 App 會自動辨識 Big5、HKSCS、GB18030 等編碼。若仍有亂碼，歡迎附上檔名在 GitHub 回報。

筆記可以匯出嗎？
可以。在右側筆記欄底部按「匯出 Markdown…」。

我的資料會上傳嗎？
不會。所有檔案、標記與筆記都只存在你的 Mac 上，詳見隱私權政策。

Support

CHM Reader is a macOS reader for CHM e-books with Traditional Chinese support, highlights and notes. For help or bug reports, please open an issue on GitHub.
